## Requisitos recomendados

- Formato: GIF animado.
- Proporção: 16:9 (ex.: 1920 × 1080).
- Loop: contínuo, sem salto perceptível entre o último e o primeiro quadro.
- Tamanho: idealmente até 8 MB por cenário; quanto menor, melhor para celulares.
- Evite GIFs com dimensões enormes ou milhares de quadros.

A galeria detecta automaticamente quais arquivos existem. Não é necessário editar JavaScript ou cadastrar cada GIF. Os slots sem arquivo ficam ocultos.

**Importante:** use apenas imagens e animações que você tenha direito de hospedar e disponibilizar no Brazilly.
